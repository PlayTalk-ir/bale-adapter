# Qoder

1. Open repository in Qoder.
2. Enable terminal / agent shell access.
3. Custom instructions:

```
Repo: bale-adapter
Read: .ai/startup.md, .ai/capabilities/
Activate: . .\scripts\activate.ps1 OR source scripts/activate.sh
CLI: python scripts/support_cli.py
--agent id: YOUR_NAME
```

Same workflow as Cursor.
